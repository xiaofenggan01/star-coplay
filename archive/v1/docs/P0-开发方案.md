## 决策记录

| # | 决策 | 结论 |
|---|------|------|
| 1 | bridge 路径 | Mod 目录下 `bridge/`（`helper.DirectoryPath + "/bridge"`） |
| 2 | game_state 频率 | 每秒写一次全量（OnOneSecondUpdateTicked） |
| 3 | game_state 内容 | world + player + inventory + farm_summary + nearby_npcs + agent_action |
| 4 | events 清单 | 8 类型：day_started/day_ending/time_changed/inventory_changed/npc_nearby/location_changed/cmd_result/energy_low |
| 5 | events 清理 | 不清理，30h 内无需处理 |
| 6 | commands 格式 | action = tool name，params = input_schema properties |
| 7 | 批量操作模式 | 异步状态机，每 tick 一步，角色真的在走动 |
| 8 | 高价值物品阈值 | 单价 >= 300g |
| 9 | npc_nearby 去重 | 同一 NPC 进入范围只推一次，离开后再进才重推 |
| 10 | EventWatcher 策略 | 直接用 SMAPI 事件，仅 npc_nearby + energy_low 自建检测 |
| 11 | send_chat | 补入正式 command 清单 |
| 12 | 跨地图导航 | MVP 用 location 字段触发 WarpTo，Agent 侧负责拆分路径 |

## 接口契约

### BridgeManager

```csharp
public class BridgeManager
{
    string BridgeDir { get; }                           // bridge/ 绝对路径
    void Initialize();                                   // 创建 bridge/ 目录
    void Shutdown();                                     // 写 status: shutdown
    void WriteStateAtomic(string json);                  // 原子写 game_state.json
    void AppendEvent(string jsonLine);                   // 追加 events.jsonl
    int NextSeq();                                       // 递增序列号
    List<string> ReadNewCommands();                      // 读 commands.jsonl 新行
    void CleanupOnDayStart();                            // 可选：清理旧数据
}
```

### GameStateWriter

```csharp
public class GameStateWriter
{
    void WriteSnapshot(StateReader state, ActionExecutor actions);  // 构建快照并写入
}
```

调用时机：`ModEntry.OnOneSecondUpdateTicked` → `_stateWriter.WriteSnapshot()`

### EventEmitter

```csharp
public class EventEmitter
{
    void EmitDayStarted(int day, string season, int year, string weather, int unwatered, int harvestable);
    void EmitDayEnding(int day, string season);
    void EmitTimeChanged(int time, string timeDisplay);
    void EmitInventoryChanged(IEnumerable<Item> added, IEnumerable<Item> removed);
    void EmitNpcNearby(string name, int tileX, int tileY, float distance, int hearts);
    void EmitLocationChanged(string from, string to);
    void EmitCommandResult(string cmdId, bool success, string message, string? errorCode = null);
    void EmitEnergyLow(float current, float max);
}
```

调用时机：各 SMAPI 事件处理器中调用对应 Emit 方法。

### CommandProcessor

```csharp
public class CommandProcessor
{
    void Poll();   // 读新命令 → 解析 → 分发到 ActionExecutor → 回写 cmd_result
}
```

调用时机：`ModEntry.OnUpdateTicked`（每 tick）或可配置为每 N tick。

支持的 action 清单：

| action | 映射 | 参数 |
|--------|------|------|
| `navigate_to` | ActionExecutor.NavigateTo / WarpTo | x,y 或 location |
| `use_tool_on_tile` | ActionExecutor.UseToolAt | x, y |
| `equip_item` | ActionExecutor.EquipItemByName | item_name |
| `interact_with_tile` | ActionExecutor.InteractWithTile | x, y |
| `send_chat` | ActionExecutor.SendChat | message |
| `drop_item` | ActionExecutor.DropItem | item_name, count? |
| `ship_item` | ActionExecutor.ShipItem | item_name, count? |
| `cancel` | ActionExecutor.CancelCurrent | 无 |
| `water_crops` | BatchWateringAction | max_count? |
| `harvest_crops` | BatchHarvestAction | 无 |
| `go_to_bed` | GoToBedAction | 无 |

### BatchWateringAction（异步状态机）

```
状态流转：
Init → 扫描未浇水 tile → 按距离排序 → 装备浇水壶
  → [循环] NavigateTo tile → 到达 → UseToolAt → 检查体力/水量
  → 全部完成 / 体力不足 / 水壶空 → 完成，返回统计
```

## 可观测性设计

| 层面 | 手段 |
|------|------|
| **日志** | 所有 Bridge 操作通过 `IMonitor.Log` 输出，含时间戳和操作类型 |
| **文件可视** | bridge/ 目录下文件可直接 cat 查看，是最直接的调试手段 |
| **HUD 展示** | agent_action 状态在 HudOverlay 中显示（idle/navigating/watering...） |
| **测试报告** | DebugReporter 继续收集动作日志，Bridge 操作也纳入统计 |
| **错误追踪** | CommandProcessor 解析/执行失败均写入 events.jsonl 的 cmd_result |

## 可测试性设计

| 层面 | 手段 |
|------|------|
| **控制台命令** | 新增 `agent_bridge_status` 命令查看桥状态（连接/seq/最后命令） |
| **手动注入** | 可直接编辑 commands.jsonl 注入命令测试（不需要 Agent 进程） |
| **Mock Agent** | 一个简单的 Python 脚本读写 bridge/ 文件即可模拟 Agent 联调 |
| **单元隔离** | 各模块通过接口解耦，BridgeManager 可替换为内存实现 |
