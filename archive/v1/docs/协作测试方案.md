# 协作测试方案：远程编码 + 本地验证

## Context

代码在 VPS 上编写，游戏在本地电脑跑。需要建立一套**远程协作测试流程**：环境搭建指南、信息自动收集、可视化交互测试。

---

```
┌──────────────────────────────────────────────────────┐
│  1. SETUP.md — 本地环境搭建指南 + 构建脚本           │
│     (照着做即可跑起 Mod)                              │
```

## 二、可视化交互测试

### 核心决策：SMAPI 控制台命令

**为什么不做游戏内点击菜单？**

- 控制台命令实现快（10 分钟 vs 数小时）、调试友好、不影响游戏状态
- 输入命令后**直接观察游戏画面**就是可视化验证——角色会自动走动
- 每个命令的输出都是结构化的，自动收集到测试报告

### 命令列表

| 命令 | 用途 | 验证方式 |
|------|------|---------|
| `agent_status` | 打印完整状态（世界/玩家/背包） | 对照游戏画面核实 |
| `agent_npcs` | 列出当前地图所有 NPC（名字+坐标+心数） | 对照游戏画面核实 |
| `agent_objects` | 列出附近物品/作物 | 对照游戏画面核实 |
| `agent_goto <x> <y>` | 寻路移动到指定瓦片 | **观察角色自动行走** |
| `agent_goto_npc <name>` | 寻路到指定 NPC 面前 | **观察角色走向 NPC** |
| `agent_warp <location> [x] [y]` | 传送到指定地图 | **观察画面切换** |
| `agent_interact <x> <y>` | 与瓦片上物品/NPC 交互 | 观察交互效果 |
| `agent_equip <name>` | 装备指定物品 | 观察手持物品变化 |
| `agent_farm` | 打印农场概况 | 对照农场实际情况 |
| `agent_cancel` | 取消当前动作 | 角色停止移动 |
| `agent_feedback <text>` | 记录人工反馈到报告 | 报告中出现 |
| `agent_report` | 立即生成当前会话测试报告 | 报告文件出现 |

### HUD 实时状态面板（F7 切换）

在游戏画面左上角绘制半透明信息面板：

```
┌──────────────────────────────┐
│ [Agent Status] 运行中         │
│ 位置: Farm (64, 15)          │
│ 体力: 200/270  金币: 2500    │
│ 当前动作: 导航中 → (70, 20)  │
│ 上次结果: 到达目标 ✓         │
└──────────────────────────────┘
```

## 三、信息收集与同步（DebugReporter）

### 收集内容

| 类别 | 内容 | 收集方式 |
|------|------|---------|
| **动作日志** | 每个 NavigateTo/WarpTo/Interact 的参数、结果、耗时 | ActionExecutor 内部记录 |
| **错误追踪** | 异常堆栈、失败原因 | try-catch + Monitor.Log |
| **状态快照** | 每次命令执行时的完整 WorldState/PlayerState | 自动附加 |
| **卡住事件** | 卡住检测触发记录 | StuckDetector 上报 |
| **人工反馈** | 用户通过 `agent_feedback` 输入的文本 | 追加到报告 |
| **会话元数据** | 游戏版本、SMAPI 版本、Mod 版本、测试时间 | 自动收集 |

### 报告格式（JSON）

```json
{
  "session_id": "2026-03-22T18-30-00",
  "metadata": {
    "game_version": "1.6.14",
    "smapi_version": "4.5.2",
    "mod_version": "0.1.0",
    "started_at": "2026-03-22T18:30:00",
    "ended_at": "2026-03-22T19:15:00"
  },
  "action_log": [
    {
      "timestamp": "18:31:05",
      "action": "NavigateTo",
      "params": { "x": 64, "y": 15 },
      "result": "success",
      "duration_ms": 3200,
      "state_before": { "tile": [60, 10], "energy": 270 },
      "state_after": { "tile": [64, 15], "energy": 270 }
    }
  ],
  "errors": [],
  "stuck_events": [],
  "user_feedback": [
    { "timestamp": "18:35:00", "text": "角色走到一半停住了" }
  ]
}
```

### 同步方式：SSH rsync 直推

报告写入 Mod 本地 `test-reports/` 目录，通过 rsync 直接推送到 VPS：

```bash
# 单次同步
./scripts/sync-logs.sh

# 持续监听模式（文件变动自动同步，需 brew install fswatch）
./scripts/sync-logs.sh watch
```

**为什么不用 git？** 测试日志是临时数据，走 git 会污染 commit 历史。rsync 更快、更干净，且 `test-reports/` 已加入 `.gitignore`。

**数据流向**：Mod 写入 `Mods/StarCoPlay/test-reports/` → rsync → VPS `~/happyclaw/data/groups/.../star-coplay/mod/test-reports/` → Agent 容器内直接读取分析。

## 四、协作工作流

```
         服务器 (VPS)                    本地电脑 (Mac)
    ┌─────────────────┐            ┌─────────────────────┐
    │  编写 C# 代码    │──git push──→│  git pull            │
    │                  │            │  ./scripts/build.sh   │
    │                  │            │  启动游戏             │
    │                  │            │                       │
    │                  │            │  SMAPI 控制台:        │
    │                  │            │  > agent_status       │
    │                  │            │  > agent_goto_npc Sam │
    │                  │            │  > agent_feedback ... │
    │                  │            │  > agent_report       │
    │                  │            │                       │
    │  分析报告        │←─rsync/SSH─│  ./scripts/sync-logs  │
    │  修复问题        │            │                       │
    │  git push        │──────────→│  git pull → 重新测试  │
    └─────────────────┘            └─────────────────────┘
```

## 五、验收测试场景（按优先级）

| # | 场景 | 命令 | 通过标准 |
|---|------|------|---------|
| 1 | Mod 加载 | 启动游戏 | SMAPI 控制台显示 "StardewAgent Demo 已加载" |
| 2 | 状态读取 | `agent_status` | 输出的时间/位置/体力与游戏画面一致 |
| 3 | NPC 列表 | `agent_npcs` | 列出的 NPC 名字和位置与画面一致 |
| 4 | 同地图寻路 | `agent_goto 64 15` | **角色自动行走到目标瓦片** |
| 5 | NPC 寻路 | `agent_goto_npc Abigail` | **角色自动走到 Abigail 面前** |
| 6 | 跨地图传送 | `agent_warp Town` | **画面切换到城镇** |
| 7 | 物品交互 | `agent_interact <x> <y>` | 目标物品产生反应 |
| 8 | 卡住恢复 | 导航到被阻挡的位置 | 5 秒后自动取消并报告 |
| 9 | 报告生成 | `agent_report` | test-reports/ 下出现 JSON 文件 |

## 明确不做的事

- **不做游戏内点击菜单** — 控制台命令更快更可靠，黑客松后期可升级
- **不做 Windows 适配** — 开发环境为 macOS
- **不走 git 同步日志** — 日志是临时数据，走 SSH rsync 直推，不污染 commit 历史
- **不做截图自动采集** — SMAPI 无直接截图 API，手动截图 + feedback 更实用
- **不做自动化测试框架** — 黑客松阶段人工验证即可
