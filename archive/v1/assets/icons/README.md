## 使用说明

所有图标均为 PNG 格式，可以直接在网页中使用。

示例:
```html
<!-- 使用图标 -->
<img src="icons/Abigail_Icon.png" alt="Abigail" width="32" height="32">

<!-- 在CSS中作为背景 -->
<style>
  .npc-icon {
    background-image: url('icons/Abigail_Icon.png');
    width: 32px;
    height: 32px;
  }
</style>
```

## 技术说明

- 使用 Chrome CDP (Chrome DevTools Protocol) 爬取
- 通过 baoyu-url-to-markdown skill 获取网页内容
- 从缩略图URL自动提取原始完整大小图标
- 批量下载并使用正确的文件名
- 所有图标均为完整大小（非32px缩略图）
